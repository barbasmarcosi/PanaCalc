# PanaCalc V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a fully local/offline PanaCalc V2 beta with mass-unit conversion, pieces mode, fixed-gram-safe scaling, preferments, a deterministic fermentation planner, improved local presets, safe V1 migration, and an isolated `/PanaCalc-V2/` preview while V1 stays live.

**Architecture:** Grams remain the canonical calculation unit. New pure domain modules resolve unit conversion, production targets, preferment partitioning, and schedules; React hooks adapt transient input strings to those domain APIs; storage is versioned and channel-aware so preview and production cannot contaminate each other. The V2 source stays in `barbasmarcosi/PanaCalc`; a separate static Pages repo pulls and builds the V2 branch for beta testing.

**Tech Stack:** React 19, TypeScript 5.9, Vite 7, Vitest 3, Testing Library, CSS, vite-plugin-pwa, Node 24, GitHub Actions / GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-05-panacalc-v2-design.md`

## Global Constraints

- No backend, accounts, authentication, cloud database, or cross-device sync.
- No import/export in V2.
- All dough-domain calculations use grams internally.
- Supported mass units are exactly `g`, `kg`, `oz`, and `lb`.
- Exact factors: `1 kg = 1000 g`, `1 oz = 28.349523125 g`, `1 lb = 453.59237 g`.
- Percentage ingredients scale; fixed absolute-mass ingredients never scale.
- Water remains percentage-based and non-removable.
- Percentages above 100 remain legal.
- Preview uses `panacalc.preview.*.v2`; production uses `panacalc.*.v2`.
- Preview must never mutate V1 keys.
- Production migration must never delete V1 data and must be idempotent.
- V1 remains at `https://barbasmarcosi.github.io/PanaCalc/` until explicit promotion.
- V2 beta target is `https://barbasmarcosi.github.io/PanaCalc-V2/`.
- Production and preview service-worker scopes must stay isolated.
- PanaCalc V1 release commit is `1b9836678bac81ee4a415ac2cc1ee9222b43c188`; the requested `v1.0.0` tag must point exactly there when a tag-capable GitHub path is available.

## Review Focus

1. **Changing a mass unit must preserve the physical quantity** — e.g. `453.59237 g → 1 lb → 16 oz`; pin in Task 1 and Task 6.
2. **Scaling total-mass mode with fixed grams must hit the scaled total without scaling the fixed ingredient**; pin in Task 2 and Task 6.
3. **Pieces count must reject fractions and zero instead of silently rounding**; pin in Task 2 and Task 7.
4. **Multiple preferments must never consume more total flour or water than the formula contains**; pin in Task 3 and Task 8.
5. **Preview storage on the same `github.io` origin must never read/write V1 or production-V2 keys**; pin in Task 5 and Task 11.
